## 🚀 Como Começar (3 Passos)

### 1️⃣ Instalar
```bash
cd DubrasilNexa
npm install
```
⏱️ **Tempo:** 2 minutos

### 2️⃣ Rodar Localmente
```bash
npm run dev
```
⏱️ **Tempo:** 1 minuto  
📍 **Acesso:** http://localhost:3000

### 3️⃣ Deploy
```bash
npm run build
# Arraste /dist para netlify.com/drop
```
⏱️ **Tempo:** 1-3 minutos  
🎉 **Resultado:** Site ao vivo!
