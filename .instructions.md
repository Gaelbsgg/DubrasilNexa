# Instruções Personalizadas - DuBrasil Nexa Landing Page

## 🎯 Visão Geral do Projeto

Este projeto é uma **Landing Page Premium** para a DuBrasil Nexa - plataforma de atendimento inteligente com foco em "Tecnologia Humanizada".

**Tecnologia Stack:**
- React 18.3 + Vite 5.0
- Tailwind CSS 3.4
- Framer Motion 11
- Inter Typography (ExtraBold títulos)

## 🎨 Conceito de Design

**Tema:** Tecnologia Humanizada
- **Color Scheme:** Dark mode (dark-950 base)
- **Primary:** Azul técnico (0ea5e9)
- **Accent:** Verde vibrante (10b981)
- **Animações:** Suaves, elegantes (0.4s-0.8s)

## 📐 Estrutura de Componentes

Cada componente segue padrão:
1. Variantes Framer Motion (containerVariants, itemVariants)
2. Seção com header/título
3. Conteúdo principal (cards, grid, ou layout)
4. Elementos visuais decorativos

## ✍️ Guia de Conteúdo

Todos os textos mantêm a **essência da apresentação original**:
- Proposta de valor: "organiza, centraliza, aplica inteligência"
- Diferencial humanizado: atendimento acolhedor e natural
- Foco em integração: Atendimento + CRM + ERP
- Resultados mensuráveis: velocidade, satisfação, eficiência

## 🎭 Padrões de Animação

- **Entrada:** fade-in + slide-up (0.6s)
- **Hover:** Scale (1.05) + translate-y (-5px)
- **Stagger:** 0.15-0.2s entre filhos
- **WhileInView:** Ativa ao scroll

## 📱 Responsividade

- **Mobile-first approach**
- **Breakpoints:** sm, md, lg
- **Tipografia escalável:** Base → 7xl
- **Spacing:** Generoso whitespace

## 📞 Customização Comum

### Mudar cores:
`tailwind.config.js` → colors object

### Adicionar seção:
Criar novo arquivo em `src/components/` seguindo padrão

### Modificar tipografia:
`tailwind.config.js` → fontFamily e fontSize

### Ajustar animações:
Editar `containerVariants` nos componentes
